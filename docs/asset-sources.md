## Earth Textures

- Files: `public/assets/earth-surface.jpg`, `public/assets/earth-clouds.png`
- Source: [Three.js planets texture collection](https://threejs.org/examples/textures/planets/)
- Note: the surface texture derives from NASA Blue Marble and is used for the Three.js Earth and cloud layers.

## Country Boundaries

- File: `public/assets/countries-110m.geojson`
- Source: [Natural Earth](https://www.naturalearthdata.com/) 1:110m Admin 0 Countries
- License: public domain
- Use: low-emphasis global boundaries that help beginners locate find regions

The 1:110m dataset replaces a previous 1:50m file, reducing the uncompressed boundary asset from about 3 MB to 0.84 MB. It supports global orientation and is not suitable for legal or administrative boundary decisions.

Item-level meteorite image authors, file pages, review status, and licenses are listed in [image-sources.md](image-sources.md).
